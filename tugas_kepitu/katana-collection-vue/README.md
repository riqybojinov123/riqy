# Katana Collection — Vue Practicum

Website katalog koleksi replika katana dekoratif untuk tugas praktikum Vue.js.

## Fitur
- Vue 3 + Vite
- Vue Router: halaman Beranda (`/`) dan Daftar Pilihan (`/cart`)
- Pinia: state keranjang, tambah/kurangi/hapus item
- Komponen `ProductCard.vue`
- Tiga produk contoh untuk display/collectible

## Menjalankan project
Pastikan Node.js dan npm sudah terpasang.

```bash
npm install
npm run dev
```

Buka alamat lokal yang muncul di terminal, biasanya `http://localhost:5173/`.

## Build
```bash
npm run build
```

Catatan: Produk di katalog merupakan contoh replika tumpul/dekoratif untuk pajangan, bukan senjata fungsional. Keranjang hanya simulasi praktikum dan tidak memproses transaksi.
